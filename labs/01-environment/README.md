# LAB 01 - Reproducible Network Lab Environment

## Objective

Prepare a reproducible networking lab environment using Docker and Containerlab.

## Environment

- Ubuntu Linux
- Docker
- Containerlab
- VS Code
- Alpine Linux containers

## Lab

A basic two-host topology was created using Containerlab.

The topology and IP configuration are defined in `lab01.clab.yml`, allowing the environment to be destroyed and recreated without manual network configuration.

## Validation

Connectivity between both containers was verified successfully after redeploying the lab.

## Conclusion

The base environment is ready for the upcoming networking and network security labs.
